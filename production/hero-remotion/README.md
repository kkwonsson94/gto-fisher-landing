# GTO Fisher 动画源码

正式合成：`GTO-Fisher-Hero-Polish`。在仓库根目录执行 `npm run studio` 编辑；`npm run build` 打包正式网页动画。两者都不会自动渲染导出视频。

`npm run assets` 从仓库内的 assets/ 和 production/hero/sources/assistant.png 准备 Studio 资源。原版与扑克试验合成保留作对照。正式网页不会读取 URL 参数切换到试验动画。

版本冻结于 2026-10-27，保留光效柔边修复，不包含用户撤回的结尾强光和额外模糊版本。完整运行说明见根目录 README.md。
